# 02 · 交互与视觉规范（UX / UI）

> 本文档规定主站（Atoms Demo 本身）的页面、布局、组件、文案和视觉。生成出来的应用的设计规范见 [08-templates.md](08-templates.md) §2。

## 1. 设计原则

1. **像一个产品，不像一个表单**：大留白、清晰层级、动效克制（150–200ms）。
2. **过程可见**：任何等待超过 1 秒的操作都有进度反馈；智能体在做什么永远一目了然。
3. **错误可恢复**：每个错误提示都附带下一步动作（重试 / 回退 / 重新生成）。
4. **只有浅色主题**：主站不做暗色模式（节省时间），生成的应用可以是暗色。

## 2. 视觉基础

基调：**首屏深色科技感 + 内容区明亮中性色 + 橙红点缀**。首屏和模板区用深色底（`--night`），叠加淡网格、缓慢漂移的彩色光晕（橙 / 青 / 蓝）、粒子连线画布和流动渐变描边；内容区为明亮中性色。刻意避开"紫色渐变 + 星星图标"一类常见的 AI 产品外观。Tailwind CSS v4，组件在 `src/components/ui/` 手写。`src/app/globals.css` 用 `@theme` 把 `zinc` 灰阶换成略暖的中性灰，并定义以下变量：

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#FF5A1F`（橙红） | 主强调：焦点、标题渐变字、悬浮、图标底 |
| `--brand-ink` | `#D63D06` | 浅底上的强调文字（"当前"、"模板：xx"） |
| `--brand-soft` | `#FFEADF` | 选中背景、标签背景 |
| `--ink` | `#15161A` | 主按钮、用户气泡、版本号 |
| `--night` | `#0A0D12` | 首屏、模板区、页脚的深色底 |
| `--signal` | `#27D3C3` | 青色信号色：终端提示符、扫描线 |
| `--bg` | `#F7F7F5` | 页面背景 |
| `--panel` | `#FFFFFF` | 卡片、面板背景 |
| `--border` | `#E5E5E0` | 边框 |
| `--text` | `#15161A` | 正文 |
| `--muted` | `#6B6B64` | 次要文字 |
| `--success` | `#16A34A` | 通过、完成 |
| `--warning` | `#D97706` | 查看旧版本提示条 |
| `--danger` | `#E5372A` | 错误 |

- 字体：系统字体栈（PingFang SC / 微软雅黑）；拉丁字母和编号点缀用 Georgia 斜体（`.font-display`，Windows / macOS 自带）；代码用系统等宽字体。**不加载任何网络字体或 CDN 资源**（服务器在国内）。
- 字号：正文 14px；首页 Hero 54px（手机 34px），区块标题 28px。
- 圆角：卡片 12–16px，按钮和输入框 8px。
- 阴影：只用于首页输入框、首屏演示窗口和悬浮层；普通卡片用边框。
- 动效：入场 320ms、滚动淡入 600ms、头像"呼吸"外圈表示角色正在工作；`prefers-reduced-motion: reduce` 时全部关闭，首屏演示直接显示最终画面。
- 图标：`lucide-react`，统一 16px（按钮内）或 20px（独立）。

### 2.1 智能体角色

| 角色 key | 显示名 | 主色 | 头像插画 | 职责一句话 |
|---|---|---|---|---|
| `pm` | Mia · 产品经理 | `#F5A524` | 齐肩短发、圆框眼镜、手拿写字板 | 理解需求，选模板，列功能 |

### 4.0 首页结构（从上到下）

1. 顶栏：标志（三个错开的圆点，对应三位角色）+ 锚点导航（团队 / 模板 / 我的项目）+ 恢复码。
2. 首屏（深色）：终端风格提示行、标题（"能用的"为橙色渐变字）、说明、输入框（流动渐变描边）（占位文字轮换示例需求，底部显示三位角色小头像）、输入框下方一排"应用风格"卡片（暖纸墨色 / 像素风 / 明亮卡片，每张带迷你预览，默认选中上次用过的、首次为暖纸墨色；第四张"其他风格"把"整体风格："接到需求末尾让用户自己写）、示例按钮；右侧"生成过程演示"窗口，按真实流程循环播放：输入需求 → Mia 拆功能 → Leo 填配置 → 预览出现 → Iris 检查通过 → 打卡格子被勾上。纯前端假数据，离开视口或切到后台时暂停。下方一行数据条（模板数 / 交付时长 / 修复轮数 / 注册步骤）和滚动的需求跑马灯。
3. 我的项目。
4. 01 · 一支三个人的小队：三张角色卡，各带一句"工作中会说的话"。
5. 02 · 八个打磨过的模板（深色区）：8 张卡，点击把示例需求填进输入框（不直接提交）。
6. 03 · 不止生成一次：自动修复、版本、分享、免注册、下载 HTML。
7. 页脚。

文案原则：说具体的事（"最多修两轮，修不好就退回上一个能用的版本"），不用"赋能 / 智能 / 一键生成未来"之类的空话。

### 4.1 示例提示词（固定 4 个，定义在 `src/lib/examples.ts`）

| 按钮标题 | 图标 | 提交的完整提示词 |
|---|---|---|
| 习惯打卡 | ListChecks | 做一个每日习惯打卡应用，可以添加习惯，每天打卡，显示连续打卡天数和最近 7 天的完成情况 |
| 个人记账 | Wallet | 做一个个人记账本，记录收入和支出，按分类统计本月花销，并用饼图展示支出构成 |
| 招聘看板 | SquareKanban | 做一个招聘流程看板，列分别是：待筛选、一面、二面、Offer、已入职，卡片记录候选人姓名、岗位和备注 |
| 记忆翻牌 | Gamepad2 | 做一个记忆翻牌小游戏，用水果 emoji，记录步数和用时，保存最好成绩 |

样式：输入框下方一排胶囊按钮，悬浮时上浮 1px、边框变墨色、图标变朱红；点击直接创建项目。

### 4.2 我的项目卡片

- 内容：标题（单行省略）、`v{当前版本 seq}` 标签、相对时间（"刚刚 / 5 分钟前 / 2 小时前 / 3 天前 / 2026-11-20"）、模板名标签（如"记账本"或"自由生成"）。
- 悬浮时右上角出现 `⋯` 菜单：重命名、删除。
- 无项目时：虚线框，文案"还没有项目。写一句需求，或者点上面的例子，做好的应用会出现在这里。"
- 加载中：3 个骨架卡片。

### 4.3 恢复码菜单（E6）

下拉弹层内容：
- 说明文字："恢复码可以在其他设备上找回你的项目，请勿泄露给他人。"
- 只读输入框显示恢复码 + "复制"按钮。
- 分隔线后："使用其他恢复码"输入框 + "切换"按钮。切换成功后刷新页面；恢复码不存在时提示"恢复码无效"。

## 5. 工作台 `/p/[id]`

### 5.1 桌面布局（宽度 ≥ 1024px）

```
┌──────────────────────────────────────────────────────────────────────┐
│ ← ◆  记账本 ✎     [v3 ▾]                       [分享] [下载] [⋯]      │ 顶栏 56px
├────────────────────────┬─────────────────────────────────────────────┤
│ 对话面板（默认 420px）   │ [预览] [代码]          [↻] [📱/🖥] [重置数据] │ 工具栏 44px
│                        │─────────────────────────────────────────────│
│  用户气泡                │                                             │
│  Mia 卡片                │            iframe 预览                       │
│  Leo 卡片                │                                             │
│  Iris 卡片               │                                             │
│  版本卡片 v1             │                                             │
│  …                      │                                             │
│────────────────────────│                                             │
│ [输入框            ][↑] │                                             │
└────────────────────────┴─────────────────────────────────────────────┘
```

- 分栏用 `react-resizable-panels`，左栏最小 320px、最大 50%，默认 420px，宽度存 localStorage（`atoms:ui:panel`）。
- 对话面板内部自动滚动到底部；用户向上滚动后停止自动滚动，并在底部显示"↓ 新消息"浮动按钮。
- 顶栏：`←` 回首页；标题可点击编辑（失焦或回车保存，Esc 取消，最长 40 字）；版本下拉；分享、下载按钮；`⋯` 菜单含"删除项目"。

### 5.2 手机布局（宽度 < 1024px）

- 顶栏下方是分段控件 `[对话] [预览]`，二选一全屏显示。
- 生成完成时若当前在"对话"，分段控件的"预览"上出现小红点。
- 代码 Tab 在手机上隐藏（只保留预览）。

### 5.3 对话流中的消息类型

| 类型 | 外观 |
|---|---|
| 用户消息 | 右对齐气泡，`--brand` 底色白字，最大宽度 85% |
| 智能体活动卡片 | 左对齐全宽卡片：头像 + 角色名 + 状态 + 耗时；正文区按角色展示（见 §5.4） |
| 版本卡片 | 细边框条：`v3` 徽标 + 版本名 + 来源标签（模板 / 配置 / 自由生成 / 补丁 / 修复 / 手动，映射见 01 AC-5.1）+ 时间；当前版本右侧显示"当前"，可点击进入查看模式 |
| 系统消息 | 居中灰色小字，如"已恢复到 v2""已停止" |
| 错误消息 | 红色边框卡片，原因 + "重试"按钮 |

### 5.4 智能体卡片的状态与内容

状态图标：`running` 转圈（`Loader2` 动画）、`done` 绿色对勾、`error` 红色叉、`stopped` 灰色方块。

| 角色 | running 文案 | done 正文 |
|---|---|---|
| pm | 正在分析需求… | 一句回复（`reply`）+ "模板：记账本" 标签 + 功能要点列表（3–6 条） |
| engineer（模板/配置） | 正在填写应用配置… | "已生成应用配置" + "查看配置"折叠区（JSON，等宽字体，最高 240px 滚动） |
| engineer（自由生成） | 正在编写代码… 已写 3.2k 字符 | "已完成代码编写（12.4k 字符）" |
| engineer（补丁） | 正在修改代码… | "修改了 N 处" + 折叠区显示每个补丁的 SEARCH/REPLACE 摘要 |
| qa | 正在检查运行情况… | "检查通过 ✓" 或 "发现 N 个问题：" + 错误列表（每条单行，最多 3 条）+ 修复轮次 |

卡片耗时：右上角 muted 小字，如 `4.2s`，running 时每秒刷新。

### 5.5 输入框（工作台底部）

- 输入框上方一行"风格"按钮（纸墨 / 像素 / 明亮，当前风格为黑底高亮；自定义风格时额外显示其名称）。点击即换风格：模板应用不调用模型，瞬间出新版本；生成中禁用。

- 自动增高 1–6 行；`Enter` 发送，`Shift+Enter` 换行。
- 生成中：输入框禁用，占位文案"团队正在工作…"，发送按钮变为红色"停止"按钮。
- 首个版本生成前且失败时：输入框上方显示"重新生成"按钮。
- 输入框上方可出现一条提示条（限流提示、连接中断提示）。

### 5.6 预览区

- 工具栏左侧 Tab：`预览` | `代码`。右侧：刷新（重新挂载 iframe）、设备切换（P2，桌面 100% / 手机 390px 居中带外框）、重置应用数据（二次确认）。
- 生成中且没有任何版本：预览区显示居中插画区：三个角色头像依次跳动 + 文案"团队正在为你搭建应用…"。
- 自由生成流式过程中：自动切到"代码"Tab 显示流式代码（只读），完成后自动切回"预览"。模板路径不切换。
- 查看旧版本时：预览区顶部黄色提示条（`--warning` 浅底）："正在查看 v2 · 版本名（只读）  [恢复此版本] [返回当前]"。
- 预览运行时报错（非自动修复流程中，如用户点击按钮后报错）：预览区底部浮出红色条"应用出现了 1 个错误 [查看] [让测试员修复]"。

### 5.7 代码 Tab

- 使用 CodeMirror 6（`@uiw/react-codemirror` + `@codemirror/lang-html`），只读，显示当前查看版本的完整 HTML。
- 右上角："复制代码"按钮（失败降级为全选）。
- 模板版本额外显示一个切换 `[HTML] [配置 JSON]`。

### 5.8 版本下拉

- 触发器：`v3 ▾`。
- 列表项：`v3 记账本加备注字段 · 补丁 · 10:24`，当前项有"当前"标签，`status=error` 的项有红点"有问题"。
- 点击列表项 = 进入该版本的查看模式（与点版本卡片相同）。

### 5.9 分享弹窗

- 标题"分享应用"。
- 开关"公开访问"（默认关）。说明："开启后，任何拿到链接的人都可以使用这个应用（只读，不能看到对话）。"
- 开启后显示链接输入框（只读）+ "复制"按钮 + "打开"按钮。
- 链接使用 `window.location.origin + '/share/' + id`。

## 6. 分享页 `/share/[id]`

- 整页只有一个全屏 iframe（`100vw × 100dvh`，无边框）。
- 右下角固定徽标（`fixed bottom-3 right-3`，半透明白底、圆角胶囊、12px）："◆ 由 Atoms Demo 生成"，点击新标签打开首页。
- P2 Remix：徽标旁"复制一份来改"按钮。
- 页面 `<title>` 用项目标题。

## 7. 全局反馈组件

- Toast：使用 shadcn `sonner`，右下角，3 秒自动消失。用于：重命名成功、复制成功、删除成功、恢复成功。
- 确认弹窗：shadcn `AlertDialog`。删除项目文案："删除后无法恢复，确定删除「标题」吗？"；重置数据文案："将清空这个应用里保存的所有数据，确定吗？"。
- 空状态、骨架屏：首页项目列表、工作台加载中（左侧 3 个骨架卡片，右侧灰色块）。

## 8. 文案规范

- 全部中文，句末不加句号的场景：按钮、标签、标题、Toast。完整句子加句号。
- 称呼用户为"你"。
- 错误文案模板："<发生了什么>，<下一步>"。例如："模型响应超时，请重试"。
- 所有错误码与中文文案的映射集中在 `src/lib/errors.ts`（见 [06-api-spec.md](06-api-spec.md) §2）。

## 9. 可访问性与细节

- 所有图标按钮有 `aria-label` 和 tooltip。
- 焦点可见（shadcn 默认 ring）。
- 首页输入框自动聚焦。
- 工作台 `<title>`：`<项目标题> · Atoms Demo`。
- 相对时间每分钟刷新一次即可。
