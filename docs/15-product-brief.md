## 一、产品是什么

**Atoms Demo**：一个"说一句话，就得到一个能用的小应用"的 AI 应用生成器，参考 atoms.dev 的核心体验实现。

用户用自然语言描述想要的应用（例如"做一个每日习惯打卡，显示连续天数和最近 7 天完成情况"），一支**看得见的 AI 团队**分工完成：

- **Mia（产品经理）**：理解需求，拆成功能点，选择最合适的模板和风格；
- **Leo（工程师）**：生成应用，或在后续对话里修改它；
- **Iris（测试员）**：检查代码、在浏览器里实际运行，发现报错自动修复。

几十秒后，右侧沙箱里出现一个可以直接操作、数据会保存的单页应用。之后可以继续对话修改、查看与回滚历史版本、切换风格、生成公开分享链接或下载 HTML。**无需注册，打开即用。**

## 二、核心体验流程

1. 首页输入一句需求（或点一个示例），可先选风格：暖纸墨色、像素风、明亮卡片，或用文字描述如"赛博朋克"。
2. 进入工作台，左侧三张角色卡片实时显示 Mia、Leo、Iris 的进度；自由生成时代码逐字流式出现。
3. 右侧预览可直接使用：添加数据、刷新页面，数据仍在。可切换桌面 / 手机宽度。
4. 继续对话修改："把主色改成橙色，标题改成喝水小助手"。改动以新版本出现。
5. 版本时间线中查看任意历史版本，一键恢复。
6. 一键开启公开分享链接，或下载单文件 HTML（双击即可运行）。
7. 用恢复码在另一台设备找回自己的项目。

## 三、实现思路

**约束**：时间 6–8 小时；只用 DeepSeek Flash（低成本模型）；部署在自有云服务器。
**核心判断**：低成本模型写长代码不稳定，所以不赌模型能力，而是**用工程手段换稳定性**。

1. **模板优先、配置驱动**。8 个精修模板（待办、记账、表单、看板、落地页、仪表盘、小游戏、记录管理）。Mia 先把需求分类，Leo 只需输出几 KB 的 JSON 配置，由服务端渲染成完整应用。模板覆盖不了的需求才走"自由生成整页"。
2. **多步短输出 + 严格校验**。每一步都是小 JSON，用 zod 校验；不合法就把错误喂回模型重试，仍失败则降级为自由生成，保证主流程一定有结果。
3. **自动修复闭环 + 回退**。Iris 做静态检查（结构、外链白名单、语法），再在浏览器沙箱里加载应用收集运行时报错，带行号交给 Leo 修复，最多 4 轮；仍失败就回退到上一个可用版本。**用户永远不会停在一个坏掉的版本上。**
4. **补丁式修改**。追问修改时：模板应用直接改配置；其他应用用 SEARCH/REPLACE 补丁只改需要改的部分，失败才整页重写。输出更短、更快，也不丢已有内容。
5. **一套模板 × 多套主题**。颜色、字体、圆角、阴影全部是 CSS 变量，风格只是一组变量值。换风格是纯渲染，不调用模型、不花 token。
6. **单文件 HTML + 安全沙箱**。生成物是一个 HTML 文件，用 `srcdoc` 在 iframe 中秒开，零构建失败、不占服务器资源。iframe 不给同源权限；应用数据通过 postMessage 垫片保存到父页面，刷新后仍在。
7. **工程化与可交付**。Next.js + SQLite（Drizzle）+ Docker Compose + Nginx 部署在自有服务器，SSE 流式推送；每一步都写入数据库，刷新后对话、卡片、版本完整恢复。访客 / IP / 全站三级限流防滥用。`LLM_MOCK=1` 模式下无需 Key 也能完整演示，E2E 测试全部在 mock 下运行。

**成本**：模板路径估算约 $0.0013 / 次，自由生成约 $0.005 / 次（非高峰价）。实测：`<平均每次生成的 token 与费用，来自 npm run usage>`。

## 四、关键取舍

| 选择 | 理由 | 代价 |
|---|---|---|
| 只用 DeepSeek Flash | 成本极低，适合公开演示 | 代码能力有限 → 用模板、校验、修复兜底 |
| 模板优先 | 低成本模型也能稳定产出精致应用 | 应用类型受模板限制，模板外走自由生成 |
| 单文件 HTML | 秒开、可静态检查、可按行号定位报错 | 规模上限约 3 万字符，不支持多文件工程 |
| 匿名访客 + 恢复码 | 评审打开即用 | 没有真正的账号体系 |
| 自有服务器 + Docker | 长时间流式生成不受 Serverless 时长限制 | 需要自己运维 |
| SQLite | 单机零运维 | 只适合单实例，扩容需换 Postgres |
| 手写状态机 | 三步流程透明、易调试 | 流程变复杂时需迁移到 LangGraph 等框架 |

## 六、与 Atoms 的对比

**做到的**：自然语言生成应用并实时预览、可见的多智能体团队、对话式修改、版本回滚、分享与导出；另外做了 Atoms 没有强调的"测试员自动修复 + 失败回退"、免注册使用和零成本换风格。

**没做的**：生成应用自带后端 / 数据库 / 登录 / 支付（类 Atoms Cloud、Supabase、Stripe）、一键部署与自定义域名、深度调研智能体、竞速模式（多模型并行择优）、多文件框架工程、团队协作与计费。

**为什么**：这些每一项都是独立子系统，且会放大低成本模型的不稳定性。6–8 小时内优先保证"一句话 → 一个能用的东西"这条主流程稳定可靠，其余列入后续规划。

## 七、后续规划

1. 多文件 React 工程（WebContainer），突破单文件规模上限。
2. 把高质量的自由生成结果沉淀为新模板，形成数据飞轮。
3. 点选编辑：在预览中点元素直接提修改。
4. 竞速模式：同一需求多模型并行，用户择优。
5. 生成应用自带后端与数据库、一键部署到子域名。
6. 流程迁移到 LangGraph 支持断点续跑；配置域名与 HTTPS。
